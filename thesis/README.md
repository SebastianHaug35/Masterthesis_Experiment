# Masterarbeit – Texte

Exportierte Stände der beiden Planungsdokumente. Bearbeitet wird in den Claude Docs; diese Dateien sind Kopien (Markdown) für die Versionierung.

- `gliederung.md` – Planung: Kapitel, Seiten, offene Entscheidungen, Schreibplan
- `entwurf.md` – die Arbeit selbst, wächst von oben nach unten; Abschnitte mit „abgesegnet“ sind vom Autor Satz für Satz freigegeben

Weitere Kopien liegen als Google Docs im Drive-Ordner „Masterarbeit“.
